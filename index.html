Cross-Listing Helper Privacy Policy

Effective October 5, 2026 · Local development prototype, version 0.3

This policy describes the current Cross-Listing Helper Chrome extension and its companion service running on your computer. It is a separate application from AI Listing Writer. It is not affiliated with or endorsed by eBay, Poshmark, Depop, or Mercari.

Information used by the application

The extension saves item information you enter or import: titles, descriptions, prices, brands, sizes, colors, conditions, eBay listing identifiers and links, source photo URLs, and destination draft edits.

If you configure eBay import, the companion service uses a seller-authorized eBay user access token to request active listings and details of an item you select through eBay's official APIs. API responses can contain additional seller, listing, or transaction-related information. The service passes responses to the extension for processing; the extension saves the item fields described above rather than the complete API responses.

Where information is stored

Saved items and drafts are stored in Chrome's local extension storage on your computer. This version does not use Chrome Sync or an application cloud database. Backups you export are saved as JSON files wherever you choose to download them.

The eBay access token is configured in a local .env file and read into the companion service's memory. It is not stored in extension storage or backups. The file is plain text and should be kept private. The service generates a temporary pairing key, displayed in its command window and entered into the extension page. The key changes when the service restarts.

How information is used and shared

Item information is used to prepare and review listing drafts, retain your edits, and export backups. The companion service sends your access token and listing requests to eBay to perform imports. This version does not send your saved inventory to an application operator's server, sell it, use it for advertising, or send it to an AI provider. It includes no application analytics or advertising trackers.

Copy buttons place the chosen text or URL on your clipboard. If you load photo previews or open a source photo, original listing, or destination marketplace, your browser connects to that third-party website. Photo previews load only when you request them. If you paste information into a marketplace, that marketplace receives it under its own policies. Opening Mercari's importer does not automatically transfer data or publish a listing.

Retention and deletion

Items remain in local extension storage until that storage is cleared or the extension is uninstalled. Exported backups remain until you delete the files yourself. To remove the locally configured token, stop the companion service and remove it from the .env file or delete that file. Stopping the service clears its in-memory session data. You can also revoke application access through eBay's account controls.

The operator does not maintain a separate cloud copy of your inventory. Other people or software with access to your computer may be able to access local files or data; this prototype does not provide encrypted storage.

This policy website

When hosted on GitHub Pages, this page is served by GitHub. GitHub may process technical request information, such as your IP address, under its own privacy statement. This page contains no forms, analytics scripts, or external fonts.

Questions and changes

For privacy questions about this prototype, contact the maintainer through the Issues section of the GitHub repository publishing this page. Do not post passwords, access tokens, private inventory, or other sensitive information in a public issue.

If future versions add cloud storage, additional marketplace connections, analytics, or other data processing, this policy will be updated to describe those changes. The effective date at the top identifies this version.
